# shared/

`deck-ink.js` and `present.js` are a copy of [lecture-deck-tools](https://github.com/smkatz12/lecture-deck-tools) **v1.0.0**.

This copy changes only when updated on purpose, so a change to the tools never affects a lecture mid-quarter. To update: copy the two files from the new lecture-deck-tools release over these and change the version above.
